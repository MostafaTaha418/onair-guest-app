# Home layout proposals

These three previews use the supplied coastal screenshot only as an illustrative
image. Property names, prices, and counts in the previews are sample content,
not live application data.

The shared header, search, filter shortcut, favorites shortcut, and bottom
navigation are already implemented. The choice determines the order and size
of the existing destination and apartment sections:

1. `home_option_1.png`: one prominent destination card, then apartments.
2. `home_option_2.png`: two destination cards side by side, then apartments.
3. `home_option_3.png`: apartments first, then compact destination links.

The previews are generated by
`test/features/home/goldens/home_variants_preview_test.dart`.
